# Security

**Last Updated: July 25, 2026**

## Security at Oxiom

Security is fundamental to how we build and operate Oxiom Invoice Processing. We are committed to protecting your data and maintaining your trust.

## Data Protection

### Encryption
- **In Transit**: All data is encrypted using TLS 1.2+ with 256-bit encryption
- **At Rest**: Invoice and customer data are encrypted using AES-256 encryption
- **Backups**: Backup data is encrypted and stored securely

### Access Controls
- Role-based access control (RBAC)
- Multi-factor authentication (MFA) for user accounts
- Principle of least privilege for internal staff
- Regular access reviews and audit logs

### Data Centers
- Enterprise-grade cloud infrastructure
- Physically secured data centers
- Disaster recovery and business continuity
- Geographically distributed redundancy

## Compliance & Standards

### Current Compliance
- GDPR ready for EU and UK customers
- SOX compliance support for internal controls
- HIPAA-ready architecture (available for healthcare organizations)

### Security Standards
- NIST Cybersecurity Framework alignment
- ISO/IEC 27001 controls (in progress)
- OWASP Top 10 mitigations
- Regular penetration testing

## Operational Security

### Monitoring & Threat Detection
- 24/7 security monitoring
- Intrusion detection and prevention systems
- DDoS mitigation
- Anomaly detection and alerting

### Incident Response
- Incident response plan and procedures
- 24-hour incident investigation
- Customer notification within 72 hours of confirmed breach
- Post-incident analysis and improvements

### Security Updates
- Monthly security patches for all infrastructure
- Quarterly penetration testing
- Annual third-party security audits
- Continuous vulnerability scanning

## User Security

### Account Protection
- Strong password requirements
- Multi-factor authentication (MFA)
- Session timeout after inactivity
- Secure password reset process

### Best Practices
- Keep your password secure
- Enable MFA
- Log out when using shared computers
- Report suspicious activity immediately
- Keep browser and antivirus software updated

## Vendor Management

### Third-Party Security
- Vendor security assessments
- Data Processing Agreements (DPA) with all subprocessors
- Regular vendor compliance reviews
- Contractual data protection requirements

## Audit & Compliance

### Audit Trail
- Complete logging of all user actions
- Invoice status and approval history
- User login and access history
- Data modification tracking
- Export and deletion audit logs

### Compliance Reports
- Invoice processing timeline reports
- Exception and issue reports
- User access and approval authority reports
- System activity and security logs

## Data Retention & Deletion

### Data Retention
- Invoice data retained per your subscription agreement
- Configurable retention policies
- Automatic deletion after retention period
- Immediate deletion upon customer request

### Secure Deletion
- Data destroyed using cryptographic erasure
- Backup data purged within 30 days
- Certificate of destruction provided upon request
